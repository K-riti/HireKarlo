## Why Contributions Weren't Showing

**Root Cause**: Git was configured with `kriti@example.com`, but GitHub account uses `elimasharma2@gmail.com`

**GitHub's Contribution Rules**:
- ✅ Commit email must match verified email on GitHub account
- ✅ Commit author name doesn't matter (can be anything)
- ✅ Multiple emails can be added to GitHub account
- ❌ Unmatched emails = commits visible but no contribution count

**Fix Applied**:
```bash
git config user.email "elimasharma2@gmail.com"
```

**Result**: All new commits now credited to your GitHub profile
